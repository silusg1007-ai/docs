## Recommended Study Sequence

Following a consistent sequence for each AP topic will help you build understanding, apply it in a lab context, and then practice the exam-style questions that pull both together.

<Steps>
  <Step title="Watch the concept video">
    Start with the concept video for the topic to build or refresh your understanding of the core ideas before jumping into practice.
  </Step>
  <Step title="Run the virtual lab">
    Complete the corresponding virtual lab to apply the concept hands-on. Collect your data carefully — you'll need it for the next step.
  </Step>
  <Step title="Attempt the analysis questions">
    Work through the post-lab analysis questions using your own data. These questions are structured the same way AP free-response questions are written.
  </Step>
  <Step title="Download your lab report">
    Save your completed lab report. It's useful for review before the exam and can be included in a course portfolio if your teacher requires one.
  </Step>
</Steps>

<Tip>
  Start with the concept video for each topic, then run the corresponding virtual lab, then attempt the practice analysis questions — this sequence mirrors how AP exam questions are structured, moving from recall to application to analysis.
</Tip>
